- CompactionConfig 在 io.agentscope.harness.agent.memory.compaction（非官方文档写的 core 包）
- LongTermMemoryMode：AGENT_CONTROL/STATIC_CONTROL/BOTH；mem0 客户端 core 内置（Mem0LongTermMemory）
- 单机默认 JsonFileAgentStateStore（~/.agentscope/state/<agentId>/）；生产 RedisAgentStateStore / DistributedStore 一键装配
- 关键坑：不配 RuntimeContext 会串台到 defaultSessionId；IsolationScope 上线后不可改；Remote filesystem + 本地 stateStore → build 抛 IllegalStateException
