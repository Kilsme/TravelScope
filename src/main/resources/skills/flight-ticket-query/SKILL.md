# 飞机票查询技能

## 能力边界（重要）

高德 Web 服务 API **不提供**实时航班票价与余票数据。本技能提供的是：
- 城市机场查询（真实数据：机场名称、地址、经纬度）
- 双城机场组合与航线参考信息

**严禁编造航班号、票价、余票**——这些信息一律标注「待确认，以航司官网或订票平台为准」。

## 何时使用

- 跨城（尤其远距离，如 1000 公里以上）行程的大交通规划
- 确认城市有哪些机场、机场位置（用于规划往返机场交通）

## 可用工具

- `searchFlightTickets(originCity, destinationCity, date)`：双城飞机方案，返回出发/到达机场列表与参考说明
  - `date`：出发日期，必须 `yyyy-MM-dd` 格式
- `searchAirports(city)`：单城市机场查询，适合只确认机场位置的场景

## 使用要点

1. 拿到机场列表后，可用机场的 `location`（经纬度）调用 `getTransitRoute` / `getDrivingRoute` 规划「市区↔机场」的接驳交通
2. 大城市有多个机场时（如北京首都/大兴、上海虹桥/浦东），提示用户根据住宿位置选择更便利的机场
3. 与火车方案对比时说明：飞机需提前 1.5-2 小时到机场，门到门时间未必比高铁短
4. 返回 `error` 字段时如实告知

## 输出建议

- 列出推荐起降机场及理由（距市区/住宿点的远近）
- 机票价格统一写「待确认」，预算估算时给出区间提示并请用户自行核实
