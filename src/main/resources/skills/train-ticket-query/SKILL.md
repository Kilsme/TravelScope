# 火车票查询技能

## 何时使用

- 跨城行程中规划城际大交通（火车/高铁）
- 用户直接询问两地间的火车方案

## 可用工具

- `searchTrainTickets(originCity, destinationCity, date)`：查询双城火车方案
  - `originCity` / `destinationCity`：城市中文名（如 "上海"、"北京"），工具内部自动做地理编码
  - `date`：出发日期，必须 `yyyy-MM-dd` 格式（如 "2026-09-15"）

## 使用要点

1. 返回的 `plans` 是最多 5 套换乘方案，每套含总耗时 `duration`（秒）、`cost`（参考费用）和 `train_segments`（火车段列表：车次、出发/到达车站、出发/到达时间）
2. 优先推荐火车段少（直达优先）、总耗时短的方案；中转方案要说明中转站
3. 结果中的票价是高德参考价，**实际票价与余票必须以 12306 为准**——输出时务必保留这一提示
4. 若用户没说出发时间，默认按白天出发（工具内部按 08:00 后方案查询）
5. 返回 `error` 字段时（如城市未找到、无方案），如实告知，不要编造车次

## 输出建议

- 推荐 1-2 套方案：车次、出发站/到达站、出发/到达时间、历时、参考票价
- 与飞机方案对比时，结合门到门总耗时（火车站通常比机场更靠近市区）给出建议
