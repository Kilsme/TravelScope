# 火车票查询技能

## 何时使用

- 跨城行程中规划城际大交通（火车/高铁）
- 用户直接询问两地间的火车方案或车次余票

## 可用工具（MCP：12306）

工具名前缀为 `mcp__c12306__`，常用调用链如下：

1. `mcp__c12306__get-current-date`：获取今天日期（上海时区，yyyy-MM-dd）。用户说"明天/下周三"等相对日期时必须先调用此工具解析
2. `mcp__c12306__get-tickets`：查询实时余票（核心工具）
   - `date`：查询日期，`yyyy-MM-dd` 格式，不得早于当天
   - `fromStation` / `toStation`：出发/到达地，支持**中文城市名或车站名**（如 "北京"、"上海虹桥"），也可用站点电报码
   - `trainFilterFlags`（可选）：车次筛选，如 "GD"=高铁+动车、"ZT"=直达+特快
   - `earliestStartTime` / `latestStartTime`（可选）：出发时间窗（0-24 整点）
   - `sortFlag`（可选）：startTime/arriveTime/duration 排序
   - `format`：建议传 "json"，便于结构化展示
3. `mcp__c12306__get-interline-tickets`：无直达时的中转余票（前 10 条，可指定 `middleStation`）
4. `mcp__c12306__get-train-route-stations`：查询某车次（如 "G1033"）的经停站

## 使用要点

1. 返回的是 12306 实时余票数据（车次、出发/到达站与时间、历时、各席别余票与票价）
2. 优先推荐直达车次；无直达或余票紧张时改用 `get-interline-tickets` 查中转，并向用户说明中转站
3. 用户没说出发时间时，可用时间窗参数（如 6-22 点）过滤夜间车次，并按出发时间或历时排序
4. 余票实时变动，**购票请以 12306 为准**——输出时务必保留这一提示
5. 工具报错（如站名无法识别、日期过早）时如实告知，不要编造车次或余票

## 输出建议

- 推荐 1-3 个车次：车次、出发站/到达站、出发/到达时间、历时、二等座/一等座等主要席别余票与票价
- 与飞机方案对比时，结合门到门总耗时（火车站通常比机场更靠近市区）给出建议
