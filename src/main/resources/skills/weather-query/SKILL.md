# 天气查询技能

## 何时使用

- 用户询问某城市当前天气或未来几天天气
- 行程规划中需要按天气安排室内/室外活动、给出穿衣与装备建议

## 可用工具

- `getWeather(city)`：实时天气。返回温度、体感温度、天气状况、风向风力、湿度、能见度等
- `getWeatherForecast(city, days)`：天气预报。days 仅可选 3/7/10/15/30，其他值会回落为 3 天

## 使用要点

1. 行程规划场景优先用 `getWeatherForecast`，天数与行程天数对齐（超过 7 天的行程用 7 天预报即可，并在结果中注明远期天气存在不确定性）
2. `city` 传城市中文名即可（如 "北京"、"成都"），无需带"市"字
3. 工具返回 `error` 字段时（如 API Key 未配置、城市未找到），不要编造天气数据，如实告知用户并标注「天气信息待确认」

## 输出建议

- 行程中按天给出：天气状况、最高/最低温、风力
- 基于天气给出具体建议：雨具、防晒、穿衣厚度、室内外活动调整
